OpenPanel v0.1.0 is the first installable Windows preview for 1920 x 550
touchscreen secondary displays.

## Highlights

- Native .NET 10 WPF host with a bundled TypeScript/WebView2 dashboard.
- Live CPU, GPU, memory, storage, and network telemetry.
- Windows media controls, artwork, playback state, seek, and shuffle.
- Global audio-output switching and an expanded audio control center.
- Weather and air quality with compact and expanded layouts.
- Peripheral batteries, on-demand network diagnostics, process usage, and
  manually activated PresentMon gaming metrics.
- Touch and mouse paging, persistent widget arrangement and sizing, themes,
  tray-only operation, and per-widget visibility controls.

## Install

Download `OpenPanel-Setup-0.1.0.exe` below and run it. The installer is
self-contained, installs for the current user, adds a Start Menu shortcut, and
supports clean uninstall. Starting OpenPanel with Windows and creating a
desktop shortcut are optional installer choices and are off by default.

Microsoft Edge WebView2 Evergreen Runtime is required. It is already present on
most current Windows 10 and Windows 11 systems.

This preview is not yet Authenticode-signed, so Microsoft Defender SmartScreen
may show an unrecognized-app warning. The adjacent `.sha256` file contains the
release artifact checksum.
